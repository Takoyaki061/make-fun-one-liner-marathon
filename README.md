Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun.

`main.py` (Python standard library only) writes a single one-line comedy
joke, 133 characters, to `/output/entry.txt`. The joke was brainstormed with
DeepSeek (10 candidates, critique-picked — see `CANDIDATES.md`).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
